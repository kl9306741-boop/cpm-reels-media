# cpm-reels-media

Repositório destinado a testes de transferência de vídeos **públicos** do CPM
(ponte temporária entre Claude Code e Metricool via GitHub Releases).

- Somente vídeos finais já autorizados para divulgação pública.
- Nenhum arquivo privado, credencial ou dado pessoal.
- Vídeos são anexados como assets de Releases, nunca commitados no repositório.
- Sem Git LFS e sem GitHub Actions.
